# All Synapse folders

This page lists every FunGen-xQTL folder on the AD Knowledge Portal, with its Synapse ID, its files and the catalog pages that describe it. In file names, `*` stands for one file per gene, region or batch.

The list is rebuilt from `data/statfungen_synapse_staging_folder_structure.yml` on every site build. All folders are controlled access; [How to get the data](how_to_get_data.md) gives the steps.
